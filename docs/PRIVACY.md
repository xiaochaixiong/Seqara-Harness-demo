# 公开版隐私边界

此仓库从清理后的源文件建立新的 Git 历史，不继承内部版本的提交、用户配置或业务材料。

## 不包含的内容

- 真实公司与院校名单、原业务 PPT、逐页渲染、照片及参考稿。
- 个人路径、内部验收记录、旧运行日志与开发缓存。
- 模型 API Key、Cookie、云服务密钥、工作区和会话数据。
- 分发权限未确认的 PPT 编译引擎、模板与摄影素材。
- 原有安装包、虚拟环境和 node_modules。

## 运行时数据

默认存放在 `%APPDATA%/SeqaraHarnessDemo`。此目录不属于公开仓库，不自动导入其他安装的数据。导出文件、诊断记录及会话可能涉及个人资料，使用者应自行检查备份及分享范围。

联网模型与视觉工具会向所配置的服务发送请求。通过插件市场安装的扩展需分别审查其来源和权限。不要将自己的运行目录添加进 Git。

## 检查方法与限制

`scripts/audit-public.py` 检查 Git 跟踪及未忽略的文件、常见凭据格式、个人用户路径、受限文件名和 Office XML。测试另行验证公开版数据目录、空名单、模板无嵌入图片和外链、移除的制作引擎未被注册。

扫描不能证明任意文字、图片或压缩数据均无隐私，新增素材必须人工复核。发现已公开的真实凭据时应立即撤销或轮换，并按 GitHub 的敏感数据移除流程处理历史。
